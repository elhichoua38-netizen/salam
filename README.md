# 🔔 صفحة إشعارات يتحكم بها بوت تلغرام

## الفكرة (بشكلها الصحيح)

1. بوت التلغرام يعطيك **رابطاً** لصفحتك.
2. توزّع الرابط على الناس.
3. من يفتح الرابط **تظهر له نافذة «السماح بالإشعارات»** فيوافق عليها ← يصبح مشتركاً.
4. **أنت** تكتب أي رسالة للبوت في تلغرام ← الرسالة تصل **كإشعار على موبايل كل مشترك** — حتى لو أغلق الموقع أو خرج منه.

> مثال: عندك قناة/صفحة، تريد أن يصل «منشورك» للأشخاص كتنبيه على هواتفهم بدون أن يفتحوا تطبيقاً.

## 📁 بنية المشروع

```
telegram-push-notify/
├── bot.py                     ← بوت تلغرام: يعطي الروابط ويبثّ الرسائل
├── requirements.txt
├── package.json               ← مكتبات دوال Netlify
├── netlify.toml
├── public/                    ← صفحة الاشتراك (تُرفع على Netlify)
│   ├── index.html
│   ├── style.css
│   ├── app.js                 ← يطلب إذن الإشعارات ويُسجّل الجهاز
│   ├── sw.js                  ← خدمة الاستقبال: تعرض الإشعار على الموبايل
│   └── manifest.webmanifest
├── netlify/functions/
│   ├── subscribe.js           ← يحفظ أجهزة المشتركين
│   └── broadcast.js           ← يوزّع الرسالة إشعاراً لكل الأجهزة
└── .env.example               ← قيم جاهزة للمتغيرات السرية
```

### مسار الرسالة

```
أنت تكتب رسالة للبوت في تلغرام
        ↓
 bot.py يرسلها (بالسر المشترك) إلى دالة broadcast على Netlify
        ↓
 الدالة ترسلها Web Push عبر خدمات كروم/فايرفوكس/سفاري
        ↓
 تظهر إشعاراً على موبايل كل شخص سمح بالإشعارات
```

## ⚙️ 1) إنشاء البوت

1. افتح **@BotFather** → `/newbot` → خذ **التوكن**.
2. (اختياري) معرّفك الرقمي من **@userinfobot** — أو اترك `OWNER_ID = 0` وأرسل `/start` من حسابك أول مرة فيُضبط تلقائياً.

## ⚙️ 2) تجهيز `bot.py`

عدّل أعلى الملف:

```python
BOT_TOKEN        = "123456:ABC-xyz..."   # من @BotFather
SITE_URL         = "https://اسم-موقعك.netlify.app"
BROADCAST_SECRET = "5ef71a...06742b"     # القيمة مضبوطة مسبقاً — انقلها كما هي لـ Netlify
```

شغّل:

```
pip install requests
python bot.py
```

## 🚀 3) الرفع على Netlify

> ⚠️ **السحب والإفلات لا يشغّل الدوال** — استخدم إحدى هاتين الطريقتين:

### الطريقة أ (الأسهل): GitHub
1. ارفع مجلد المشروع كاملاً إلى مستودع GitHub جديد.
2. [app.netlify.com](https://app.netlify.com) → **Add new site → Import an existing project** → اختر المستودع → **Deploy**.

### الطريقة ب: سطر الأوامر
```
npm install -g netlify-cli
netlify login
cd telegram-push-notify
netlify init
netlify deploy --prod
```

## 🧪 5) التجربة

1. `bot.py` يعمل عندك.
2. أرسل للبوت `/new` ثم افتح الرابط **بموبايلك (Chrome/Edge)** — وليس في تلغرام نفسه.
3. اضغط «🔔 تفعيل الإشعارات» ثم **السماح** ← ستظهر رسالة «أنت مشترك».
4. ارجع للبوت واكتب أي رسالة عادية (مثل: مرحبا بالجميع).
5. خلال ثوانٍ سيصلك **إشعار** على موبايلك حتى لو أغلقت الصفحة. 🎉

> للاختبار المحلي قبل الرفع: `netlify dev` ثم افتح `http://localhost:8888/?c=1a2b3c4d5e6f`
> (الاختبار المحلي يحتاج إعداد المتغيرات أيضاً).

## ❓ أسئلة مهمة

**هل تعمل على الآيفون (Safari)؟**
إشعارات الويب على iOS تبدأ من **iOS 16.4** لكن فقط إذا أضاف المستخدم الصفحة للشاشة الرئيسية (Add to Home Screen) أولاً ثم فتحها منها. على **أندرويد Chrome/Edge** تعمل مباشرة، وكذلك على جميع متصفحات الحاسوب.

**هل يعمل البث إذا كان الجهاز بعيداً عن الموقع؟**
نعم — هذا جوهر Web Push: الإشعار يُرسل من خادم Netlify عبر خدمة الدفع للمتصفح، فيظهر حتى والمتصفح مغلق (مع بقاءه يعمل في الخلفية).

**هل أحتاج أن يبقى bot.py شغالاً؟**
لإنشاء الروابط وللبث نعم. كل مشترك جديد يُسجَّل في مخزن Netlify، لكن البث يمر عبر البوت → الأبقِ `python bot.py` شغالاً دائماً (على جهازك أو على خدمة مجانية مثل Render/Railway لاحقاً).

**كم مشتركاً يستوعب؟**
Netlify Blobs (التخزين المجاني) يكفي لعدد كبير جداً من المشتركين للمشروع الشخصي. عند الحاجة لمئات الآلاف يمكن التحويل لقاعدة بيانات.

**أريد إرسال رسائل مختلفة لمجموعات مختلفة؟**
يمكن تطوير ذلك بتخزين كل رابط بمخزنه الخاص. أخبرني إن أردته.
